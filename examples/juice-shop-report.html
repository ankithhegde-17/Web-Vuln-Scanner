Content-Security-Policy header missing

URL
http://localhost:3000/

Without a CSP the browser will run any script that ends up in the page, so a single XSS bug gives an attacker full control. CSP is the main defence-in-depth layer against XSS.

Remediation

Add a Content-Security-Policy, starting with something like "default-src 'self'; object-src 'none'; frame-ancestors 'self'" and tightening from there.

Referrer-Policy header missing

URL
http://localhost:3000/

Without an explicit policy the full URL (which may contain tokens, IDs or search terms) can be sent to third-party sites in the Referer header. Modern browsers default to a safer policy, which is why this is LOW.

Remediation

Send "Referrer-Policy: strict-origin-when-cross-origin" (or no-referrer).
